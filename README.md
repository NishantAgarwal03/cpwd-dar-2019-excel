# CPWD DAR 2019 Excel Conversion Workbooks

This repository provides two Excel workbooks produced from CPWD Delhi Analysis of Rates (DAR) 2019 PDF source material.

## Downloads

- [Volume 1 — Sub-heads 01–12](data/CPWD_DAR_2019_Vol1_PDF_Conversion.xlsx)
- [Volume 2 — Sub-heads 13–26](data/CPWD_DAR_2019_Vol2_PDF_Conversion.xlsx)

Download a workbook, open it in Microsoft Excel or compatible spreadsheet software, and use the **Cover & Index** sheet to navigate the included sub-heads. Quantity and Rate inputs drive the Amount and SAY formulas.

See the [workbook guide](docs/workbook-guide.md) and [data notes](docs/data-notes.md) before relying on any values.
